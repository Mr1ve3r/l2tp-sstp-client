# Code of conduct

## The standard

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The linked text is the authoritative version; it is
referenced rather than copied so that it cannot drift out of date here.

In short: everyone taking part — contributors, reviewers, people filing issues
— is expected to make this a project others can take part in. Harassment,
personal attacks, and derogatory remarks about who someone is are not
acceptable, in the repository or anywhere the project is represented.

## Scope

It applies in the issue tracker, in pull requests and reviews, in commit
messages, and wherever someone is acting as a representative of this project.

## What this means in review

Reviews here are direct, and they should be. A change to a VPN client that
weakens what the application will accept as a server needs to be told so
plainly. Directness is about the change; the standard above is about the
person. "This accepts an expired certificate — see the pre-flight check" is a
good review. Remarks about the author are not, no matter how wrong the patch.

## Reporting

Report a problem privately to the maintainers rather than in the thread where
it happened. Use GitHub's private report flow on the
[Security tab](https://github.com/Mr1ve3r/l2tp-sstp-client/security) — it is the
private channel this repository has, and it works for conduct reports as well as
for vulnerabilities.

Reports are handled confidentially. Give what you can: where it happened, what
was said, and links. You will get a reply.

## Enforcement

Maintainers may edit or remove comments, commits and issues that violate this
code of conduct, and will say when they do. Repeated or severe behaviour leads
to a temporary or permanent ban from the project's spaces. The Contributor
Covenant's enforcement ladder is what these decisions follow.
